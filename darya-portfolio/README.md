# Портфолио — Дарья Жирнова

Сайт-визитка на чистом HTML/CSS. Без сборки и зависимостей.

## Публикация на GitHub Pages

1. Создайте репозиторий **`<ваш-логин>.github.io`** (тогда сайт будет по адресу `https://<ваш-логин>.github.io`).
   Можно и любое другое имя — тогда адрес будет `https://<ваш-логин>.github.io/<имя-репо>`.
2. Загрузите в корень репозитория `index.html` и `photo.jpg` (кнопка **Add file → Upload files**).
3. **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save.**
4. Через 1–2 минуты сайт будет доступен по ссылке.

## Как редактировать
- Тексты — прямо в `index.html`.
- Фото — замените `photo.jpg` (любое соотношение сторон, не обрезается).
- Цвет акцента — переменная `--accent` в начале `<style>`.
- Телефон скрыт в комментарии в блоке контактов — раскомментируйте, если нужно.
